# ObrProfi — Установка на чистый компьютер

Пошаговая инструкция для развёртывания локальной среды разработки.

> Связанные документы:
> - `РЕГЛАМЕНТ.md` — правила работы, деплой, миграции
> - `СТРУКТУРА_ПРОЕКТА.md` — структура файлов, как создавать/редактировать элементы
> - `.1_пороли` — все доступы


---

## 1. Установить ПО

| Программа | Ссылка | Зачем |
|---|---|---|
| **Docker Desktop** | https://www.docker.com/products/docker-desktop/ | Локальный сервер (PHP + MySQL) |
| **PuTTY** | https://www.putty.org/ | SSH-доступ к серверам (plink + pscp) |
| **VS Code** | https://code.visualstudio.com/ | Редактор кода |
| **Git** (опционально) | https://git-scm.com/ | Контроль версий |

### Docker Desktop
1. Скачать, установить, перезагрузить компьютер
2. Запустить Docker Desktop, дождаться зелёного индикатора
3. Проверить: `docker --version` и `docker-compose --version`

### PuTTY
1. Скачать, установить
2. Добавить в PATH: `C:\Program Files\PuTTY\`

### VS Code — расширения

Открыть VS Code → **Ctrl+Shift+X** → поиск "MODX" → Install:

| Расширение | Автор | Зачем |
|---|---|---|
| **IntelliSense for MODX** | Gulomov | Подсветка тегов MODX `[[...]]`, автодополнение pdoTools, fenom |
| **vscodemodx** | Pavel Bihel | Подсказки кода MODX Revolution |

Настройки проекта уже включены в `.vscode/settings.json`:
- `.tpl` файлы открываются с подсветкой **MODX** (не HTML)
- Emmet работает в MODX-файлах как в HTML

После установки расширений внизу справа VS Code должно показывать **"MODX"** при открытии `.tpl` файлов. Если показывает "HTML" — кликните на "HTML" внизу → выберите "MODX".

## 2. Получить файлы проекта

### Вариант А — Клонировать из Git (рекомендуется)

```bash
git clone git@github.com:MEDSTANDARTPROF-cmp/op-site-back.git d:\Project\ObrProfi
```

Для доступа к репозиторию нужно быть добавленным в организацию `MEDSTANDARTPROF-cmp` на GitHub.
Попросите админа добавить ваш GitHub-аккаунт.

### Вариант Б — Из архива

Получить файл `ObrProfi_FULL.tar.gz` от коллеги и распаковать в `d:\Project\ObrProfi\`.

### Структура проекта

```
d:\Project\ObrProfi\
├── .1_пороли                 ← доступы
├── УСТАНОВКА.md              ← этот файл
├── РЕГЛАМЕНТ.md              ← правила работы
├── СТРУКТУРА_ПРОЕКТА.md      ← структура и инструкции
├── .vscode\                  ← настройки VS Code
├── backup\
│   └── obrprofi_db_dump.sql  ← дамп БД (обязательно!)
├── docker\
│   ├── docker-compose.yml
│   ├── Dockerfile
│   └── php.ini
├── scripts\                  ← скрипты деплоя и миграции
└── site\                     ← файлы сайта MODX (обязательно!)
    ├── assets\
    ├── core\
    │   └── elements\         ← статичные элементы (шаблоны, чанки и т.д.)
    ├── connectors\
    ├── manager\
    └── ...
```

Если папки `site\` или файла `backup\obrprofi_db_dump.sql` нет — скачать с сервера:
```bash
bash scripts/pull-db-from-prod.sh
```

## 3. Настроить конфиги MODX

Убедитесь, что в конфигах прописаны **локальные** значения:

### `site\config.core.php`, `site\connectors\config.core.php`, `site\manager\config.core.php`
```php
define('MODX_CORE_PATH', '/var/www/html/core/');
```

### `site\core\config\config.inc.php`
```php
$database_server = 'db';              // Docker-контейнер MySQL
$database_user = 'obrprofi';
$database_password = 'obrprofi';
$dbase = 'obrprofi';
$table_prefix = 'modx_';
$database_dsn = 'mysql:host=db;dbname=obrprofi;charset=utf8';

// Все пути — /var/www/html/
$modx_core_path       = '/var/www/html/core/';
$modx_processors_path = '/var/www/html/core/model/modx/processors/';
$modx_connectors_path = '/var/www/html/connectors/';
$modx_manager_path    = '/var/www/html/manager/';
$modx_base_path       = '/var/www/html/';
$modx_assets_path     = '/var/www/html/assets/';

$http_host = 'localhost:8080';
```

## 4. Очистить кеш и запустить

```bash
# Очистить кеш
rm -rf d:\Project\ObrProfi\site\core\cache\*

# Запустить Docker
cd d:\Project\ObrProfi\docker
docker-compose up -d --build
```

Первый запуск: 3-5 минут (сборка образа + импорт БД 194 МБ).

Проверить статус:
```bash
docker-compose ps
```

Все 3 контейнера должны быть **Up**:
- `obrprofi-web` — PHP 8.1 + Apache
- `obrprofi-db` — MySQL 5.7
- `obrprofi-pma` — phpMyAdmin


---

## 5. Проверить

| Что | URL |
|---|---|
| Сайт | http://localhost:8080 |
| Админка MODX | http://localhost:8080/manager/ |
| phpMyAdmin | http://localhost:8081 |

Логин в админку: `proadmin` / `admin123`

Если сайт не загружается — подождите 1-2 минуты (MySQL импортирует дамп).


---

## 6. Выключить кеш (для разработки)

На локале кеш **должен быть выключен** — чтобы изменения в файлах были видны сразу.

Открыть phpMyAdmin (http://localhost:8081) и выполнить:
```sql
UPDATE modx_system_settings SET value = '0'
WHERE `key` IN ('cache_default', 'cache_resource', 'cache_scripts', 'cache_db');
```

Затем очистить кеш:
```bash
rm -rf d:\Project\ObrProfi\site\core\cache\*
```

После этого изменения в файлах видны сразу — просто обновляйте страницу.

## Устранение проблем

### Сайт показывает ошибку 500
```bash
docker-compose logs web
```

### MySQL не запускается
```bash
docker-compose logs db
```

### Пересоздать всё с нуля
```bash
cd d:\Project\ObrProfi\docker
docker-compose down -v
docker-compose up -d --build
```

### Обновить БД с прода
```bash
bash scripts/pull-db-from-prod.sh
```

После обновления БД с прода — снова выключить кеш (шаг 6), т.к. на проде кеш включён.
