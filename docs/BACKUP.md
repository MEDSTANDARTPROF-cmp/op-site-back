# Правила резервного копирования БД

## Когда делать бэкап

**ОБЯЗАТЕЛЬНО** перед:
- Любым импортом данных (msImportExport, скрипты)
- Массовым обновлением записей
- Изменением структуры таблиц
- Тестированием скриптов миграции

## Скрипты

### Бэкап локальной БД
```bash
bash scripts/backup-local.sh
```
- Создаёт дамп в `temp_back/backup_YYYYMMDD_HHMMSS.sql`
- Автоочистка: бэкапы старше 7 дней удаляются автоматически
- Используется mysqldump из Laragon

### Восстановление из бэкапа
```bash
# Последний бэкап
bash scripts/restore-local.sh

# Конкретный файл
bash scripts/restore-local.sh temp_back/backup_20260403_175645.sql
```
- Запрашивает подтверждение перед перезаписью

## Хранение

| Папка | Что хранит | В Git |
|-------|-----------|-------|
| `temp_back/` | Локальные бэкапы (автоочистка 7 дней) | Нет |
| `backup/` | Продовые бэкапы | Нет |

## Порядок действий при ошибке импорта

1. Остановить импорт
2. Найти нужный бэкап: `ls -lh temp_back/`
3. Восстановить: `bash scripts/restore-local.sh temp_back/нужный_файл.sql`
4. Проверить сайт: http://localhost
5. Проверить админку: http://localhost/manager/
