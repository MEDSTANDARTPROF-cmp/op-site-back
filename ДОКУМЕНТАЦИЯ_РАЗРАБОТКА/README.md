## Ключевые решения

- **WhatsApp/Telegram кнопки на сайте** — НЕ возвращаем (убраны из-за РКН-рисков). В форме как **выбор канала пользователем** — допустимо
- **CloudFlare** — НЕ используем (замедляется в РФ)
- **Сегмент «Сингапур-боты»** — не блокируем на сервере, только фильтруем в Метрике
- **Согласие на обработку ПД (предотмечанный чекбокс)** — юрист подтвердил, не правим
- **B24 поля** — используем общие UF-поля портала (которые уже настроены для medstandartprof.ru), новых не создаём
- **API Метрики** — на запись прав НЕТ, цели создаются руками через UI
