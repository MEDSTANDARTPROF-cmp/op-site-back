# Отчёт по работе над сайтом obrprofi.ru

**Период:** 30 апреля — 5 мая 2026
**Статус:** все работы на локали (Laragon, http://localhost/), прод не тронут

---

## Резюме сделанного

### 1. Аналитика и стратегия

- Глубокий аудит данных Метрики счётчика 75081295 — выявлен сломанный трекинг заявок (отвал 95% на форме B24: 1 812 кликов CTA → 99 фиксируемых заявок)
- Анализ аудитории по запросам Webmaster (топ запросов = тестовые вопросы, аудитория = профессионалы во время аккредитации)
- Изучен исходный аналитический отчёт другого агента, выявлены пробелы (B2B-канал, форма)
- Подготовлены 3 HTML-отчёта с предложениями (`ПРЕДЛОЖЕНИЯ_2026-04-30/`)

### 2. Формы и трекинг

- **Кастомная форма ObrForm в MODX** — заменяет неэффективную B24-форму на пилотных страницах
- **Микроформа на hero** (1 поле — телефон) для массового захвата на категориях курсов
- **Полная модалка с выбором канала связи** (Звонок / Email / WhatsApp / Telegram / Viber / MAX) для развёрнутых заявок
- **Маска телефона** с автоформатом, заменой 8 → +7
- **Зелёная фирменная рамка** микроформы с focus-эффектом
- **WhatsApp\* со звёздочкой** (дисклеймер про Meta в футере уже был)
- **Длинный юр. текст согласия 1-в-1 как в B24** — юрист подтвердил
- Иконки мессенджеров — официальные SVG (включая MAX с maxicons.ru)
- 8 telephone-ссылок в шаблонах подключены к цели Метрики `ym('TL')`

### 3. Точки конверсии на сайте

| Страницы | Где работают новые формы |
|---|---|
| 45 категорий каталога курсов (все) | Микроформа на hero + блок «Не нашли курс?» (полная модалка) |
| 1 615 карточек рабочих профессий | Микроформа на hero + 3 кнопки (Запросить программу, Консультация, Записаться) — все ведут на полную модалку |
| Остальные страницы (главная, блог, тесты, контакты) | Старая B24-форма продолжает работать (пока не трогаем) |

### 4. Битрикс24 интеграция

- Создан входящий вебхук с правом CRM
- Новые лиды приходят со структурированными UF-полями (URL страницы, Страница откуда, Кнопка через которую заполнили, Тип устройства) — как у medstandartprof.ru
- SOURCE_ID = `RC_GENERATOR` («Заявка с сайта obrprofi.ru»)
- В заголовке лида сразу виден канал связи: «Заявка с сайта ОБРПРОФИ (WhatsApp)» / «(Звонок)» / «(Email)» и т.д.
- Префикс `[ТЕСТ-LOCAL]` на хостах локалки (для тестовых лидов)

### 5. Метрика — цели

В кабинете Метрики настроены 7 новых целей:
- `form_open` — открытие формы
- `form_focus` — первый ввод
- `form_submit` — успешная отправка
- `form_channel_phone` / `_email` / `_messenger` — выбранный канал
- `form_b2b_submit` (на будущее)

Виртуальный hit `/spasibo.html` для совместимости со старой целью «Заявка (shems)».

### 6. SEO-инфраструктура (FAQ + статьи)

Создана инфраструктура для контента в MODX:
- TV `faq_data` (textarea, JSON со списком вопросов и ответов)
- TV `seo_article` (richtext, HTML SEO-статьи)
- Сниппет `renderFaq` — генерирует HTML аккордеон + JSON-LD schema.org/FAQPage для богатых сниппетов в Яндексе
- Чанки `FaqBlock` и `SeoArticleBlock`
- Подключение в 8 шаблонов категорий каталога
- Старый текст в TV `cont2faqNew` автоматически очищается на страницах с новым `seo_article` (с бэкапом в JSON для отката)

## Принципы работы над контентом

- **Каждая статья пишется с нуля под специфику ниши** (вариант 2, без шаблонизации)
- Структура H2 — индивидуальная для каждой ниши, не дубль между категориями
- 14-15 FAQ-вопросов на категорию, баланс ключей: 3 точных + остальные на синонимах/LSI
- Длина SEO-статьи 1500-2500 слов с таблицами (нормативка, штрафы, программы)
- Использование актуальной нормативной базы 2026 года
- Schema.org/FAQPage JSON-LD для богатых сниппетов в выдаче Яндекса
