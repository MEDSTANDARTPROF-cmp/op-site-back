### BUGFIX `/ajax-lead/` со слэшем

- **Симптом:** B2B-форма выдавала `Ошибка отправки: method_not_allowed`. POST уходил → 301 redirect → метод конвертится в GET → snippet ругается
- **Причина:** Apache на проде делает 301 redirect `/ajax-lead/` → `/ajax-lead`. Браузер при 301 (по старому HTTP-стандарту) меняет POST на GET
- **Фикс:** в `boxB2BForm` и `boxAccreditationWidget` URL `/ajax-lead/` → `/ajax-lead` (без слэша). ObrFormMini в `form.js` уже использовала правильный URL — поэтому всегда работала
- **Возможный пропущенный лид:** AccWidget на проде с утра 8 мая до 12:00 был сломан тем же багом. Скорее всего никто не успел отправить, но проверить через `b24_leads.log` не получится — отказы по этой причине логируются ДО точки записи лога
