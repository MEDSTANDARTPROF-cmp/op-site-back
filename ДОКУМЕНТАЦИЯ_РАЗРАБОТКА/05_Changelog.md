### Логирование всех попыток в `b24_leads.log`

Раньше валидационные отказы (invalid_origin, invalid_phone и т.д.) уходили молча без записи. Теперь все:

| Тип | Когда |
|---|---|
| `[LIVE]` / `[TEST]` | Запрос прошёл валидацию, отправляется в B24 |
| `[B24-OK]` lead_id=N | B24 успешно создал лид |
| `[B24-ERROR]` http=N err=... | B24 не ответил или вернул ошибку |
| `[REJECT]` reason=invalid_origin/phone/email/inn/rate_limit | Отказ на валидации, причина + details |
| `[BOT-REJECT]` reason=honeypot/too_fast | Отбит как бот (silent, без Telegram) |

### Telegram-сообщения

Для каждой записи кроме `[BOT-REJECT]` уходит сообщение в группу:

- 🟢 **НОВАЯ ЗАЯВКА → B24 #N** — полные данные лида + B24 lead_id
- 🟠 **ОТКЛОНЕНО: invalid_phone** (или другая причина) — что прислал клиент
- 🔴 **ОШИБКА B24** — http-код, curl-error
- 🟡 **RATE-LIMIT** — повторная заявка с того же телефона за минуту (наша защита)

- `build_tg_lead_text()` (closure) — формирование сообщения с полями лида: эмодзи, телефон/email/канал, источник, страница, IP, устройство, доп. строки
