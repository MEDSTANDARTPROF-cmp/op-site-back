# Битрикс24 интеграция

## Портал

`https://ecoprof.bitrix24.ru/` — единый B24-портал, обслуживающий несколько сайтов клиента (medstandartprof, gosmedobr, kadrovik.pro, obrprofi и др.). CDN-ID — `b16716304` (виден в URL B24-форм типа `cdn-ru.bitrix24.ru/b16716304/...`).

Это значит UF-поля и справочники источников **общие** для всех источников лидов на портале.

## Входящий вебхук

Создан 2026-05-04 пользователем (id=26, Александр Сусеков, Admin).

URL: `https://ecoprof.bitrix24.ru/rest/26/<token>/` — лежит **только** в `site/core/config/b24.config.php` (gitignored).

Права: только `CRM (crm)` — это вся группа CRM (lead/deal/contact/company чтение/запись). Можно ограничить точнее в B24, мы используем только `crm.lead.add`.

## Какие методы используем

| Метод | Где |
|---|---|
| `crm.lead.add` | sendLeadToB24.php — создание лида при отправке формы |
| `crm.lead.get` | scripts/get_msp_lead.php (диагностика) |
| `crm.lead.list` | scripts/get_msp_lead.php (диагностика) |
| `crm.lead.fields` | scripts/get_b24_uf_fields.php (диагностика) |
| `crm.status.list?filter[ENTITY_ID]=SOURCE` | scripts/get_b24_sources.php (диагностика) |
| `crm.lead.userfield.list` | scripts/get_b24_uf_fields.php (диагностика) |

В **продакшен-коде** (sendLeadToB24.php) используется **только** `crm.lead.add`.

## Формат запроса

```php
POST {webhook_url}/crm.lead.add.json
Content-Type: application/x-www-form-urlencoded

fields[TITLE]=...&fields[NAME]=...&fields[PHONE][0][VALUE]=...
&params[REGISTER_SONET_EVENT]=Y
```

**Важно:** B24 REST API не работает корректно с `Content-Type: application/json` для вложенных массивов (вышли пустые лиды на тестах). Использовать `http_build_query`.

## Обнаруженные особенности

### Тест-режим

Если `$_SERVER['HTTP_HOST']` совпадает с одним из `test_hosts` в config — к TITLE добавляется префикс `[ТЕСТ-LOCAL]`. Лид всё равно создаётся в B24, но менеджер видит пометку и может отфильтровать.

### Фильтрация тестовых лидов в B24

В CRM → Лиды → поиск по `[ТЕСТ` — найдутся все наши тестовые. Можно удалить пакетно через групповые действия.

## Как сменить URL вебхука

1. В B24: CRM → Разработчикам → Другое → Входящие вебхуки → создать новый или перегенерировать токен
2. Обновить `site/core/config/b24.config.php` на каждой среде (локаль/dev/prod)
3. Кеш MODX чистить не обязательно (config читается при каждом запросе)

## Что в Битриксе НЕ менялось

- Существующие триггеры/роботы/автоматизации лидов — не трогали
- Существующие формы B24 (loader_310, loader_330) — продолжают работать на остальных страницах сайта где не подключена новая форма
- Поля лидов — никаких новых UF не создавали
- Воронки/статусы — не меняли
