# ObrProfi — Структура проекта и работа с элементами

Полное описание структуры, что где хранится, и пошаговые инструкции по работе с элементами MODX.

> Связанные документы:
> - `УСТАНОВКА.md` — как развернуть проект на чистом компе
> - `РЕГЛАМЕНТ.md` — правила работы, деплой, миграции
> - `.1_пороли` — все доступы


---

## Главный принцип

Все элементы MODX хранятся как **статичные файлы** в `core/elements/`.

| Что | Где | Как редактировать |
|---|---|---|
| **Код** (HTML, PHP) | Файлы на диске | В VS Code |
| **Регистрация элементов** (имя, категория) | БД | Через админку MODX |
| **TV-поля** (определения) | БД | Через админку MODX |
| **Контент страниц** (тексты) | БД | Через админку MODX |

**Правило:** нужно изменить **как выглядит** --> правим файл. Нужно изменить **что показывается** --> правим через админку.

## Структура файлов

```
site/
├── assets/                          -- Публичные файлы (доступны из браузера)
│   ├── css/                         -- Стили

├── config.core.php                  -- Путь к ядру
```

## Форматы файлов

| Тип | Расширение | Содержимое |
|---|---|---|
| Шаблоны | `.tpl` | HTML + теги MODX (`[[*pagetitle]]`, `[[$chunk]]`) |
| Чанки | `.tpl` | HTML + теги MODX |
| Сниппеты | `.php` | PHP-код **без** тега `<?php` |
| Плагины | `.php` | PHP-код **без** тега `<?php` |

## Что где хранится

| Что | Где | Как редактировать |
|---|---|---|
| Код шаблонов (HTML) | `core/elements/templates/*.tpl` | VS Code |
| Код чанков (HTML) | `core/elements/chunks/*.tpl` | VS Code |
| Код сниппетов (PHP) | `core/elements/snippets/*.php` | VS Code |

| Имя, категория элемента | БД | Админка MODX |

| Контент страниц (тексты) | БД | Админка MODX |

| Настройки системы | БД | Админка MODX |
| Пакеты/компоненты | БД + `core/components/` | Менеджер пакетов |

## Пошаговые инструкции

### Редактирование шаблона или чанка

**Самая частая операция. БД не нужна.**

1. Найти файл в `core/elements/` по имени
2. Открыть в VS Code
3. Изменить
4. Сохранить
5. Обновить страницу (F5)

**Пример:** изменить подвал --> `core/elements/chunks/Theme/Footer.tpl` --> сохранить --> F5


### Редактирование сниппета или плагина

1. Найти `.php` файл в `core/elements/snippets/` или `plugins/`
2. Изменить PHP-код
3. Сохранить, обновить страницу

**Помните:** файлы `.php` пишутся **без** `<?php` — MODX добавляет его сам.


---

### Создание НОВОГО чанка

**Порядок: сначала файл, потом БД.**

**Шаг 1 -- Создать файл:**
```
core/elements/chunks/{category}/{chunk-name}.tpl
```
Пример: `core/elements/chunks/blocks/boxPartners.tpl`

Написать HTML-код.

**Шаг 2 -- Зарегистрировать в MODX:**
1. Админка --> Элементы --> Чанки --> "+" (новый)
2. Заполнить:
   - Имя: `boxPartners`
   - Категория: `blocks`
   - Статичный: **да** (галочка!)
   - Статичный файл: `core/elements/chunks/blocks/boxPartners.tpl`
   - Источник файлов: `Filesystem`
3. Сохранить

**Шаг 3 -- Использовать:**
```
[[$boxPartners]]
```


### Создание НОВОГО шаблона

**Шаг 1 -- Создать файл:**
```
core/elements/templates/{category}/{template-name}.tpl
```

Типичная структура:
```html
[[$Head]]
[[$Navbar]]
<main>
  <div class="container">
    [[$Crumbs]]
    <h1>[[*pagetitle]]</h1>
    [[*content]]
  </div>
</main>
[[$Footer]]
```

**Шаг 2 -- Зарегистрировать в MODX:**
1. Админка --> Элементы --> Шаблоны --> "+"
2. Имя, категория, Статичный: **да**, указать путь к файлу
3. Сохранить

**Шаг 3 -- Привязать TV-поля (если нужны):**
Открыть шаблон --> вкладка "TV" --> отметить галочками --> сохранить


### Создание НОВОГО сниппета

**Шаг 1 -- Создать файл:**
```
core/elements/snippets/{snippet-name}.php
```

Написать PHP-код **без** `<?php`:
```php
$price = $modx->getOption('price', $scriptProperties, 0);
$discount = $modx->getOption('discount', $scriptProperties, 10);
return $price - ($price * $discount / 100);
```

**Шаг 2 -- Зарегистрировать в MODX:**
1. Админка --> Элементы --> Сниппеты --> "+"
2. Имя, Статичный: **да**, указать путь к файлу
3. Сохранить

**Шаг 3 -- Использовать:**
```
[[calcDiscount? &price=`5000` &discount=`15`]]
```


### Создание НОВОГО TV-поля

**TV-поля создаются ТОЛЬКО через админку (не файлы).**

1. Админка --> Элементы --> Дополнительные поля (TV) --> "+"
2. Имя: латиница, без пробелов (например `product_duration`)
3. Подпись: человекопонятное название
4. Тип ввода: текст / число / список / и т.д.
5. Вкладка "Шаблоны" --> привязать к нужным шаблонам
6. Сохранить

Использование в шаблоне: `[[*product_duration]]`


### Создание новой категории

1. Создать папку `core/elements/{тип}/{new-category}/` (латиница!)
2. Админка --> Элементы --> Категории --> "+" --> создать с таким же именем

## Миграция между средами

### Только ФАЙЛЫ (без миграции БД)
- Правка кода шаблонов, чанков, сниппетов, плагинов
- Правка CSS, JS, картинок
```bash
bash scripts/deploy-to-dev.sh    # LOCAL --> DEV
bash scripts/deploy-to-prod.sh   # DEV --> PROD
```

### Файлы + МИГРАЦИЯ БД
- Создание новых элементов (шаблон, чанк, сниппет, плагин)
- Создание/изменение TV-полей
- Привязка TV к шаблонам
- Установка пакетов
```bash
bash scripts/migrate-db-to-dev.sh    # LOCAL --> DEV
bash scripts/migrate-db-to-prod.sh   # DEV --> PROD
```

### НЕ переносим
- Контент страниц -- заполняется на проде
- Загруженные файлы -- живут на проде
- Кеш -- генерируется автоматически

## Важные правила

1. **На локале кеш выключен** -- изменения видны сразу, F5
2. **Код правим в файлах**, не в админке MODX
3. **Имена файлов** -- только латиница, без пробелов
4. **Сниппеты/плагины** -- `.php` без тега `<?php`
5. **Шаблоны/чанки** -- `.tpl` с HTML и тегами MODX
6. **TV-поля** -- только через админку, файлов нет
7. **Метрика** -- работает только на проде (obrprofi.ru)
8. **Удалить файл = сломать элемент** -- файл на диске это источник правды
9. **Папки = категории** -- имена папок в `core/elements/` должны совпадать с категориями в MODX
